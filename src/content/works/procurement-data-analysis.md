## 应用场景

在采购及供应链日常工作中，需要频繁处理采购申请、订单、库存及供应商等数据。针对重复整理较多、人工操作耗时的问题，使用 Excel 完成基础分析，并通过自学 Python 尝试将可重复步骤程序化。

## 具体处理流程

- **数据收集：** 从日常业务表格或系统导出数据中整理需要分析的采购、订单及库存信息，明确每次分析所需字段。
- **格式统一：** 统一日期、物料名称、供应商等字段格式，对重复值、空值及明显异常记录进行基础清洗。
- **Excel 分析：** 使用筛选、排序、透视汇总等方式快速查看采购数量、订单进度、供应商及库存相关情况，形成可用于日常跟进的结果表。
- **重复步骤识别：** 将每次都需要手工执行的数据整理、字段转换、合并汇总等动作拆解出来，判断哪些步骤适合程序化。
- **Python 尝试：** 通过自学 Python 将部分重复的数据读取、清洗和汇总动作进行程序化处理，减少重复录入和机械操作。
- **结果核验：** 将程序化输出与原始数据、Excel 结果交叉检查，确保处理逻辑和结果准确后再用于后续分析。

## 能力沉淀

这项实践让我形成了“先梳理业务流程，再识别重复环节，最后用工具优化”的工作思路，能够将 Excel 数据分析与基础 Python 自动化结合到采购和供应链实际场景中。
